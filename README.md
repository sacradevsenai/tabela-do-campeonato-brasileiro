# Estrutura Web Multi-Page: Tabelas, Listas Semânticas e Navegação

Este módulo do curso prático foca na arquitetura de arquivos e na estruturação semântica de documentos HTML, evoluindo de uma página única para uma aplicação multi-página organizada.

## 🚀 Funcionalidades e Aprendizados
- **Navegação Semântica:** Uso da tag `<nav>` e links relativos (`href`) estruturados para criar um fluxo de páginas consistente e funcional.
- **Estruturas de Dados Visuais:** Renderização de dados esportivos complexos utilizando tabelas (`<table>`, `<tr>`, `<td>`) e dados geográficos com listas ordenadas/não-ordenadas.
- **CSS Modular:** Vinculação e organização de folhas de estilo externas aplicadas de forma global e por meio de classes específicas para componentização de títulos.
- **Fluxo Git Avançado:** Exercício prático de ciclo de vida de desenvolvimento utilizando branches de funcionalidades (`feature/*`), isolamento da `main`, simulação real de Code Review com aprovação externa e merge de código.
